# n8n-nodes-hookdeck

> [!WARNING]
> **This node is deprecated and is no longer maintained.**
>
> Please install and use the verified Hookdeck node, [`@hookdeck/n8n-nodes-hookdeck`](https://www.npmjs.com/package/@hookdeck/n8n-nodes-hookdeck), published and maintained by [Hookdeck](https://github.com/hookdeck/n8n-nodes-hookdeck) instead.

This is an n8n community node. It lets you use the hookdeck api in your n8n workflows.

[n8n](https://n8n.io/) is a [fair-code licensed](https://docs.n8n.io/reference/license/) workflow automation platform.
